# Foundry Highlands

A 3,203-stud closed stone track with 16 turns, including bends rotated onto diagonal straights. The track climbs from 8 to 75 studs and drops back to the level starting straight. Three level runs alternate with climbs and descents, with a maximum grade of 9.8%.

The paving and wall details come from the original track kit. An opaque mortar-colored deck runs beneath the stone courses and across section joins. The walls continue through the slopes and turns.

Import `FoundryHighlands.glb` in Roblox Studio as one Model with separate MeshParts at the original track scale. Position the imported model as a unit.

To copy your original slate, dark paving, and wall materials, keep the original textured track or the textured Foundry Switchbacks model in Workspace. With Play stopped, run `ApplyFoundryHighlandsAppearance.command.luau` in the Command Bar. Select an original textured model to give it priority. The mortar base keeps its authored color.
