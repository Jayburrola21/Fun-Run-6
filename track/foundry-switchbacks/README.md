# Foundry Switchbacks

A 1,597-stud stone track with eight wide turns, built from the original straight kit and wide bend. The stone geometry and UVs are retained, with small vertical adjustments to align the joints.

Import `FoundrySwitchbacks.glb` through the Roblox Studio 3D Importer as one Model with separate MeshParts. Use the same scale as the original track.

To copy your original textures, keep the textured track in Workspace and run the optional `ApplyDriftCircuitAppearance.command.luau` in the Studio Command Bar with Play stopped.
